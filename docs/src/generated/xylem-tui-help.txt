Open the local workflow dashboard and retained run history

Usage: xylem tui [OPTIONS] [CONFIG]

Arguments:
  [CONFIG]  Workflow configuration preloaded into the New Run action

Options:
  -v, --verbose...   Increase logging verbosity
  -q, --quiet...     Decrease logging verbosity
  -t, --threads <N>  Maximum number of Rayon workers used by Xylem (does not limit child tools)
                     [default: 10]
      --env <PATH>   Load environment variables from a specific dotenv file
      --no-progress  Disable interactive workflow progress indicators
  -h, --help         Print help
