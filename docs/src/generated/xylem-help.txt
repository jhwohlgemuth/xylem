Digital xylem that transports data through workflows with structure and support

Usage: xylem [OPTIONS] [COMMAND]

Commands:
  export  Export a workflow to another runner's configuration
  run     Run workflow using configuration file
  tui     Open the local workflow dashboard and retained run history
  help    Print this message or the help of the given subcommand(s)

Options:
  -v, --verbose...
          Increase logging verbosity

  -q, --quiet...
          Decrease logging verbosity

  -t, --threads <N>
          Maximum number of Rayon workers used by Xylem (does not limit child tools)

          [default: 10]

      --env <PATH>
          Load environment variables from a specific dotenv file

      --no-progress
          Disable interactive workflow progress indicators

      --sandbox-policy <PATH>
          Trusted operator policy used only by workflows with `sandbox: true`

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
