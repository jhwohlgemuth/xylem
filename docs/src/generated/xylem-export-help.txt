Export a workflow to another runner's configuration

Usage: xylem export [OPTIONS] --gitlab [CONFIG]

Arguments:
  [CONFIG]  Path to configuration file; discovers .xylem.* in the current directory when omitted

Options:
      --gitlab                 Write a GitLab CI configuration
  -v, --verbose...             Increase logging verbosity
      --output <PATH>          Output path for the generated configuration [default: .gitlab-ci.yml]
  -q, --quiet...               Decrease logging verbosity
      --image <IMAGE>          GitLab job image
  -t, --threads <N>            Maximum number of Rayon workers used by Xylem (does not limit child
                               tools) [default: 10]
      --env <PATH>             Load environment variables from a specific dotenv file
      --force                  Replace an existing generated configuration
      --check                  Fail when the existing output differs from the generated
                               configuration
      --no-progress            Disable interactive workflow progress indicators
      --sandbox-policy <PATH>  Trusted operator policy used only by workflows with `sandbox: true`
  -h, --help                   Print help
